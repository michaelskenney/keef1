## Section 1: Timeline Question Type (APPROVED)

### Data shape (in questions.json)

```json
{
  "id": "tl-001",
  "type": "timeline",
  "category": "albums",
  "question": "Put these albums in order of release (earliest first)",
  "albums": [
    { "name": "Sticky Fingers", "year": 1971, "image": "/images/albums/sticky-fingers.jpg" },
    { "name": "Exile on Main St.", "year": 1972, "image": "/images/albums/exile-on-main-st.jpg" },
    { "name": "Some Girls", "year": 1978, "image": "/images/albums/some-girls.jpg" }
  ],
  "points": 10
}
```

- `albums` stored in correct chronological order; app shuffles at display time
- Correctness derived by comparing player's order against sort-by-year
- No separate `answer` field needed

### UI interaction

- 3 cards in a vertical stack, each showing album cover thumbnail + album name
- Player drags cards up/down to reorder (custom pointer events — works on touch and mouse)
- "Lock In" button submits the answer
- Feedback screen shows correct order with years revealed

### Scoring (partial credit)

- Each album in correct position = `floor(basePoints / 3)` = 3 pts each
- Speed bonus: `floor(correctPositions / 3 * timeRemaining / totalTime * maxSpeedBonus)`
- 0 correct = 0 points, no speed bonus

### Type system changes

- New `TimelineQuestion` interface: `type: 'timeline'`, `albums: {name, year, image}[]`, no `answer` field
- Add `'timeline'` to `QuestionType` union and `Question` discriminated union

### Question selection

- Timeline questions fall under `albums` category weight
- No guaranteed slot (unlike lyrics/image) — enters the random pool
